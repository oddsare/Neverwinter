# Neverwinter Campaign Setting Guide

This folder contains content from the **official Neverwinter Campaign Setting** published by Wizards of the Coast for D&D 4th Edition.

## Purpose

This content has been organized separately to make it easy to:
- Reference official campaign lore
- Distinguish between official content and homebrew/custom content
- Remove all campaign guide content if desired

## How to Remove This Content

To remove all official campaign guide content from your vault:

1. Simply delete this entire `Campaign_Guide` folder
2. Or, if using Obsidian, you can exclude this folder from your graph/searches

## Current Contents

- **Chapter_1_Jewel_of_the_North.md** - Overview of Neverwinter and the North, including major locations, history, and campaign advice
- **Chapter_2_Character_Options.md** - Character themes, racial variants, warpriest domains, and the Bladesinger wizard subclass

## Additional Chapters

Additional chapters from the campaign guide can be added to this folder as needed.
